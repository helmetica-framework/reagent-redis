= Chart structure

The backup policy, the network config and the maintenance window come from xref:azoth::index.adoc[azoth], the framework's library chart, through the single include in `templates/azoth.yaml`.
The credential config stays here, in `templates/credentials.yaml`, because its mapping varies with the replica count.
The auth secret, the backup script, the rituals and the values in `values.yaml` are this chart's own too.

Everything else about the subchart is the reagent's decision and is not in the API.
See `values.yaml` for what is fixed and why.
